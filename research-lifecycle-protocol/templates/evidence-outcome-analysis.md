# Evidence Outcome Analysis report

Use the ten output items below. Do not collapse mixed effects into success/failure.
Pair this report with the source-bound packet, analysis and independent audit from
[the contract](../references/evidence-outcome-contract.md).

1. Observed outcome, result locators and exact conditions
2. Execution, protocol, measurement and evaluation validity
3. Each claim's previous/new support and affected scope
4. Each hypothesis's previous/new status and replication requirement
5. Outcome class and scientific negative versus invalid-execution distinction
6. Relevant alternatives, evidence for/against and identifying next comparison
7. Actual state delta, unchanged facts and pending scientific gaps
8. Per-target decision and post-update Assurance verdict
9. Stop/retry rule, fixes and revisit conditions
10. Next action with information gain, cost, scientific value and risk

Keep source IDs visible. Mark missing inputs unknown. Preserve negative knowledge
and prior hypotheses. Repairs requiring new science remain plans, never results.
