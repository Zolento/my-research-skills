# Acquisition Contract（MRI 物理与采集边界）

> 加载时机：R8 证据契约、R9 实验设计、以及任何涉及前向算子 / 噪声 / 采样的归因之前。

## 1. 前向模型

一般多线圈欠采样 MRI：

```text
y_Ω = A_Ω x + ε
```

- `A_Ω` 是项目契约中**逐项列出**的算子组合（coil sensitivity maps、Fourier encoding、
  undersampling mask、wave encoding、其他已确认算子）。
- 配置里 `acquisition.forward_operators` 必须逐项命名；未列出的算子**不得**在归因里隐式假定。
- 配置是规则的适用范围声明，不是第二份实验数据；每个项目的实际参数以项目契约与
  冻结预注册为准。

## 2. 可机械验证的算子检查（只在有真实证据时执行）

| 检查 | 方法 | 结论类别 |
|---|---|---|
| 维度一致性 | 算子链输入/输出维与 k-space 数据形状逐一比对 | 一致 → 排除"维度错误"；不一致 → VALIDITY_BLOCKER |
| 伴随一致性 | `<A x, y>` 与 `<x, Aᴴ y>` 数值检验（随机向量，报告相对误差） | 误差超容差 → VALIDITY_BLOCKER |
| 数据一致性 | `A x` 与测量 y 的统计偏差（零填充回代残差） | 系统性偏差 → VALIDITY_BLOCKER |
| CSM 正确性 | 线圈间相位/幅值结构与已知几何比对；低分辨率回代 | 明显错位 → VALIDITY_BLOCKER |
| 采样协议 | mask 与冻结协议比对（轨迹、密度、ACS 行数） | 不符 → VALIDITY_BLOCKER |
| 噪声假设 | 残差统计与声明模型比对 | 不符 → 记录，不得自动归因为性能瓶颈 |

**检查结果必须落到具体证据**（脚本输出、数值、文件路径）。没有执行过检查，就不得声称
"算子已验证"或"算子有问题"。

## 3. 四类区分（防止把一切塞进"forward operator 问题"）

1. **实现错误**：上表任一检查失败 → VALIDITY_BLOCKER。R10 修复优先；不得继续在同一
   缺陷上堆叠方法实验。
2. **已知物理限制**：有理论推导或严格实验支撑的不可恢复边界（如特定欠采样率下某类
   结构的信息论不可辨识），必须带**适用范围**（哪些结构、哪个采样档、什么噪声水平）。
   记为 `PHYSICAL_LIMIT_WITH_SCOPE`；范围内不得虚构可行改进，范围外不得用它阻止方法探索。
3. **方法瓶颈**：信息存在（无第 2 类证据）但当前方法/训练/表示未充分利用
   → `METHOD_TRANSITION_READY`，走 `mechanism-search.md`。
4. **无证据猜测**：口头归因（"可能是条件数问题"）且无新证据、无历史验证
   → `INSUFFICIENT_EVIDENCE`；不得写入文档结论。

## 4. 冻结边界

`frozen.components` 与 `frozen.forbidden_changes` 声明后：

- 修改冻结组件需要**用户授权的锚点/契约变更**（RLP §0.2 Anchor Change Order），
  不得因为"试过了很难"而默认解冻。
- 每个冻结项必须写明**为什么冻结**（如：隔离适配机制的贡献、保护已发表基线可比性）。
- "不允许改冻结条件"不等于"不允许在冻结条件内探索"——MMS 的六个方向全部
  在冻结边界内寻找可改变的数学对象。

## 5. 噪声与欠采样

- 噪声模型与水平是**采集事实**，不是性能解释。把"噪声高"当作失败原因时，必须引用
  噪声估计证据，并说明它与本次失败的具体因果链（否则按 §3 第 4 类处理）。
- 欠采样模式 / 加速率是**实验条件**。改变它们属于改变实验条件，需要新的预注册；
  不得在同一冻结协议下"顺手"改采样再比较结果。

## 6. 常见错误（本 Profile 明确禁止）

- 把"重建结果差"直接归因于"病态 / 欠定 / 噪声大"而不做 §2 的任何检查。
- 用一个项目的默认参数充当所有 MRI 项目的默认值。
- 在没有算子证据的情况下把 R10 修复（实现错误）写成方法否证（`falsified`）。
- 把工程性失败（OOM、NaN、崩溃）当成机制否证——RLP Core 已有此纪律，领域内同样适用。
