## 0. 执行与沟通总则

- **科学优先**：正确性由代码与测试保障、完整证据由结构化文件保存；人类报告聚焦方法、指标、机制、异常和下一步。正常通过的内部审计不逐条汇报。
- **不确定则一次性询问**：只有在已有 AGENTS、冻结协议、数据/配置及 RLP state 都不足以确定**影响训练、评价、资源、物理定义或写入范围**的事实时，Agent 才暂停相关动作，将全部相互独立的未决项集中列成一份问题清单，一次性询问用户。未获答复/授权不得擅自补默认值、改协议、跑受影响实验、修改原数据；无关的只读分析可以继续。不重复询问已回答或有权威记录的事项。冲突项提供现行两种定义、受影响实验、推荐项及理由。
- **训练前完整报告**：每一段新的训练正式启动前，向用户按编号报告数据与划分、2D/3D 和尺寸、mask 轴/ACS/加速率、输入输出及线圈约定、算子及归一化、优化器、初始 LR 与调度、epoch/step 预算、训练损失、选模方式和指标、checkpoint、代码/配置版本及算力预算。已获授权且关键配置完全不变的恢复训练仍需标注所恢复的 run 与关键一致性；若用户未授权本段训练，汇报是执行申请，不能当作授权。

## 1. MRI-01 数据划分和泄漏隔离

1. 2D 项目严格沿用已处理数据集既有 train/val/test；以 slice 作为默认重建/计算单位。不擅自重新拆分数据。若原有跨病例/相邻切片相关性，明确披露，不能称作患者独立泛化。
2. 3D 项目严格按 subject/patient 分割；来自同一 subject 的 slab、volume、patch、slice 不得跨 train/val/test。保留已有合法划分；若已有划分违反此条，先 HOLD 报告冲突，禁止私自修复后继续训练。
3. test 只在方法、超参数、checkpoint、指标口径冻结后用于最终报告；不以 test 选模或循环调试。不得把探索性结果冒充最终 test。

## 2. MRI-02 自监督信息边界与选模

1. 自监督参数更新仅从允许的测量、明确的 mask split 和自监督损失获取信息；GT 不进入输入、教师目标、梯度、loss、训练时归一化或与参数更新耦合的任何环节。具体 Θ/Λ/Ω/ACS 冻结于项目协议；不得混用切片或改 split。
2. **有完整 val GT 的项目**：在启动前冻结 `full_val_gt` 及主选模指标 `PSNR`（越大越好）或 `complex_NMSE`（越小越好），用完整 val 统一推理选择 `best_val`。允许自监督训练使用 GT 验证选模，但必须如实称为“自监督训练 + GT-assisted validation/model selection”，不可声称完全 GT-free。
3. **真正 GT-free 项目**：允许 `gt_free_frozen`；必须在训练前明确冻结不使用 GT 的选模指标、数据来源、公式、方向、评估范围和停止准则。不得把此项目强制切换至 `full_val_gt`，亦不得默认使用训练 mask-split loss 选模：只有经用户明确确认、事前冻结的 GT-free 选模方案方可使用。后续取得 GT 仅作独立外部评测/审计，不追溯用于选模。
4. 缺少验证 GT、选模指标或其合法来源时，HOLD 并一次性询问，不假装选模成功。

## 3. MRI-03 开发期子集与正式证据

1. 允许固定、可追溯的 val 子集用于 smoke、故障定位与探索性诊断。必须标识 `exploratory` 与真实样本数，不得作为正式选模、主消融或全量性能结论。
2. 正式选模、主要消融与完整验证结论使用 full val；最终 test 使用冻结的完整 test。正式机制分析可用预先定义的 ROI/子组，但要披露选择规则、覆盖率和与全量结果的关系，不能挑选样本替代整体证据。

## 4. MRI-04 物理算子、纯伴随与隐式补偿禁令

1. 明确每项目/算子的 FFT 轴、`norm`、复数 dtype、k-space 维度、采样 mask、CSM 来源、Wave/其他 encoding、噪声及坐标约定；多线圈的 CSM 来源必须满足 MRI-10。在实际调用点核对前向/伴随一致性（复内积测试）、FFT round-trip、shape、dtype 与参考尺度。
2. 对标准多线圈 Cartesian 模型，若 `A(x)=M F(Sx)`（约定 F 为所声明的 FFT），则 `A^H(y)=Σ_c conj(S_c)·F^{-1}(M y_c)`（FFT 缩放取决于项目 norm）。**规定为纯伴随的算子、ZF 初始化或评估线圈合并不得隐式加入** `D^{-1}`、`D^{-1/2}`，其中 `D=Σ_c |S_c|²`；亦不得偷偷加入采样密度权重、重归一化 CSM、按线圈能量阈值置零或将 RSS 冒充复数 SENSE 参考。
3. `D` 是线圈灵敏度能量，**不是** k-space 采样密度。单独、明确命名、由项目冻结协议允许的正规方程、SENSE 求解器、PCG 预条件器或显式重标定可使用相应权重；必须隔离于纯伴随函数，明确数学含义，不得改变 ZF/GT 的评估口径。
4. 无法确定某段代码是纯伴随还是求解器时，暂停该改动，列调用点与拟议公式一次性询问；不得为了提高 PSNR 擅加补偿。

## 5. MRI-05 统一参考尺度

1. **所有拥有 GT 的 MRI 数值评价**按每个评估样本的 **GT 幅度 RMS** `r = sqrt(mean(|x_GT|²))` 构建共同尺度：`x_GT' = x_GT/r`，`x_pred' = x_pred/r`。2D 的评估样本通常为原 slice，3D 全体积评估为完整 volume；若项目的冻结主指标另有采样单位，先作为协议冲突处理。不允许预测单独 RMS/峰值匹配、不允许事后最优缩放。
2. 当 `r=0` 或非有限值，视为无效输入并报告。GT-free 训练/选模阶段**不得**读取 GT RMS；训练输入归一化只能来自允许的训练测量、并应冻结规则。
3. PSNR 使用幅度图误差和同一 GT 幅度峰值定义 `data_range`（如对上述归一化后的 GT 取 peak）；不得以显示阶段的各图独立拉伸替代计算。SSIM 以同一 data range 与事前冻结实现计算。

## 6. MRI-06 指标口径

1. 主 NMSE 为复数 NMSE：`Σ|x_pred−x_GT|² / Σ|x_GT|²`，且从不默认等同 magnitude NMSE。
2. PSNR 与 SSIM 在幅度图上计算；`magnitude_NMSE` 如使用必须另行命名。报告均值、样本数及适当不确定性/离散度；不同口径不可直接比较。
3. 样本聚合（mean slice PSNR、global NMSE、volume mean 等）必须预先标明，不得以单个全局 aggregate 偷换逐样本平均。

## 7. MRI-07 空间尺寸与几何保持

1. 2D 主基准按处理后的原始全空间尺寸训练/验证/测试；禁止 Agent 擅自 resize、crop、转置、改变相位编码轴或不一致重采样。数据本身为 320×320 时保持 320×320。
2. 3D 可根据冻结协议采用 patch/slab 训练和固定 ROI 分析；正式评价保留原物理几何和定义好的重组/坐标映射。禁止改变 mask 与图像空间对应关系。

## 8. MRI-08 2D mask 与采样方向（强制）

1. 在 **2D 单方向 Cartesian 欠采样**中，mask **必须呈列采样（竖条纹）**：标准 `[H,W]` k-space 表示中，`M[:, j]` 在 H 方向恒定，沿 W 方向变化。禁止转为行采样/横条纹，不得通过转置图像或 mask 伪造符合性。
2. 既有 per-slice mask 必须按 subject/slice/acquisition 的真实标识精确配对，不得换共享 mask、重采样或随机生成替代。ACS/加速率/采样线数与冻结协议一致；启动前用 shape/轴/ACS/样本绑定断言校验。
3. 2D 非单方向 Cartesian（例如径向）与 3D ky-kz/Wave 任务遵循各自冻结采集契约；不得把 2D 单方向列采样假设套用到它们。发生任务类型或方向定义冲突时一次性请用户确认再执行。

## 9. MRI-09 Checkpoint 与可复现训练

1. 默认维护 `best_val` 与 `latest` 两类；`best_val` 是冻结选择协议选出的权重（GT-free 时记录具体无 GT 选模值），`latest` 为最近可继续训练状态。需保存模型、优化器、step/epoch、选择值、scheduler、AMP scaler、随机状态与采样器状态（若适用）。冻结协议授权的里程碑 checkpoint 可额外保存。
2. 保存训练实际生效的配置、代码 commit、环境、数据划分标识、mask 元数据、选模口径和指标汇总；正式输出必须能指回 checkpoint、源数据及运行 ID。
3. 未经授权不得更改预算、扩大 seed、改冻结评估或训练规范；不满足条件时 HOLD 并汇总一次性询问。

## 10. MRI-10 CSM 来源约束（新增，强制）

1. **默认且强制使用数据集存储的 CSM**：对所有非联合灵敏度估计的多线圈 MRI 重建方法，训练、验证、测试及推理中，前向/伴随算子、数据一致性、ZF/初始化、涉及线圈展开或合并的步骤，均使用数据集中与当前 subject/volume/slice/acquisition **正确配对的原始复数 CSM**。不得用 Agent 自行估计的 CSM、共享模板、其他样本的 CSM 或模型预测的 CSM 替代，也不得擅自重新估计、归一化、裁剪、平滑或改变其物理含义。只允许经过核验、保持物理值不变的维度/格式适配；相关变换必须可追溯。
2. **唯一方法类别例外：显式联合估计灵敏度**。只有研究方法自身将灵敏度 `S` 作为联合重建模型中的待估变量、可学习输出或联合优化对象，并且在**实验启动前**已在冻结方法协议中声明，才可以不采用数据集存储的 CSM 作为实际重建灵敏度。必须写明联合估计的数学定义、输入与初始化、`S` 的约束、优化/学习过程、训练与推理时的来源，以及评价时采用的线圈合并口径。该例外不意味着可以随意改变其他方法的 CSM。**仅在预处理时单独重新估计 CSM、但后续重建并不联合估计的做法，不属于此例外。**
3. 非联合估计方法发现 CSM 缺失、来源不明、样本配对不一致或与现有冻结实验设置冲突时，**HOLD 并一次性向用户汇总冲突**；不得通过重新估计、除以 `D`、使用 RSS 或从其他病例复制来隐式修复。单线圈任务无 CSM 时声明 `not_applicable`，不伪造线圈维度。
4. **必须纳入训练前报告及代码断言**：报告 `csm.mode = dataset_stored | joint_estimation | not_applicable`、真实存储来源和配对键；联合估计时给出冻结方法协议引用。检查数据加载、算子调用、模型执行、评估入口是否遵守同一声明。MRI-04 中的纯伴随和禁止隐式 `D` 补偿，在两种多线圈模式下继续生效。

## 11. 启动前用户报告标准格式

```markdown
### 01. 本轮目的与方法
- 目标、相较基线的改动、预计验证的命题

### 02. 数据和物理配置
| 数据划分 | 维度/尺寸 | mask/ACS/加速率 | CSM 模式/来源/样本配对键 | FFT/DC/归一化 |
| ... |

### 03. 训练与选模
| 优化器 | LR/调度 | epoch/step | loss | 选模指标/范围 | checkpoint | 代码/配置 |
| ... |

### 04. 资源、风险与启动决定
- 预算、授权状态、关键例外或阻塞；仅有授权才启动
```

缺项不以 `N/A` 掩盖。若触发不确定项，暂停受影响操作，一次列出全部关键问题；回答到位后复核配置，不重复询问。

## 12. 分层落地

- 权威源：Skill `domain-profiles/mri-reconstruction/training-policy.md` 的受管段；由 `scripts/mri_training.py sync-agents <project>` 注入实际项目根 `AGENTS.md`，后者不再维护第二份 MRI 文字。
- 实验真值：配置/预注册、run manifest、指标 CSV/JSON、checkpoint、state；项目特定值与未授权操作在这些对象内冻结。
- 机器检测：优先做少量关键断言（split 隔离、GT 访问、2D mask 轴、CSM 来源/样本配对/联合估计例外、FFT/adjoint、归一化、文件写入与授权）。不额外生成报告流水线或新 R 阶段。
- 面向用户：方法、训练前完整配置、可解释结果、必要异常与决策；操作明细保存在本地日志，由用户显式请求时展开。
