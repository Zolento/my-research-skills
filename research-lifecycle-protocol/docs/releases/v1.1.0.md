## 3. Fixed in this release

- **P0 账本完整性**：启动失败退款在锁内、基于重新读取的链写入，并绑定 `consume_seal`；
  重复/跨 family/伪造退款不生效。此前锁外追加会破坏哈希链 → 账本永久 `LEDGER_TAMPERED`。
- **P1 预算口径统一**：`issue()` 与 `run()` 共用 `effective_spend()`；启动失败退款后可在合法预算内
  重新签发；人工例外在预算闸门之前校验，且只解除资源限制。
- **P1 argv 语义一致**：裸命令按 PATH 解析、路径直接打开；不可启动的 `argv[0]` 在执行前拒绝；
  `LAUNCH_FAILED` 与 `EXECUTION_FAILED` 分离。
- **畸形输入**：非对象 state、空 argv、损坏账本行不再以未捕获异常终止闸门。
