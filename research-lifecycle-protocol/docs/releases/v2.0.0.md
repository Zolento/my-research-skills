# Research Lifecycle Protocol v2.0.0 — Rename + MRI Reconstruction Domain Profile

**Release date:** 2026-11-10（本分支验收日期）· **Component:** `research-lifecycle-protocol/` · **Planned tag:** `research-lifecycle-protocol/v2.0.0`
**Status:** 在 `research-lifecycle-protocol/dev` 分支验收；tag 在合并进 `main` 时创建，本版本不自行打 tag。
**Former name:** `research-idea-pipeline`（历史 tag 与 release notes 保持原名）。

---

## 1. What this release is

两件事合为一个版本：

1. **正式更名**：Skill 身份从 `research-idea-pipeline` 更名为
   `research-lifecycle-protocol`（RLP）。目录、frontmatter `name`、安装 slug、根 README
   索引与开发分支统一。机器协议命名空间与旧项目运行目录**保持不变**。
2. **MRI Reconstruction Domain Profile**：在既有 R0–R14、CIE、Research State、
   Scheduler、PEIG/AALG、Discovery Replay 与 I2M 之上新增可选领域协议
   `mri-reconstruction`，解决自监督 MRI 重建研究里 Agent 反复回退到噪声 / 算子 / 采样等
   平凡归因、方法探索停滞的问题。核心是 **TAG**（平凡归因守卫）与 **MMS**（机制到方法搜索）。

## 3. MRI Domain Profile scope

| 能力 | 说明 |
|---|---|
| `domain-profiles/mri-reconstruction/PROFILE.md` | 加载契约：显式启用、按需读取、不加载全部协议；Profile 是规则扩展，不是第二份事实 |
| `acquisition-contract.md` | 前向模型 `yΩ = AΩx + ε` 的算子清单（CSM / Fourier / mask / wave）、噪声模型、冻结组件、禁止修改条件；区分实现错误 / 物理限制 / 方法瓶颈 / 无证据猜测 |
| `ssl-contract.md` | `Ω = Θ ∪ Λ`、独立 `Ω_val`；训练信息隔离、ACS 冻结、hidden leakage、GT-free 边界；`ΔL_SSL < 0 ⇏ ΔE_image < 0` 必须记为 objective mismatch |
| `attribution-guard.md` + `scripts/domain_guard.py` | TAG 六类判定（`VALIDITY_BLOCKER` / `NOVEL_DECISION_RELEVANT_DIAGNOSIS` / `REPEATED_ATTRIBUTION` / `PHYSICAL_LIMIT_WITH_SCOPE` / `METHOD_TRANSITION_READY` / `INSUFFICIENT_EVIDENCE`）；机械规则 `TG1`–`TG9`；只阻断重复归因，不阻断真实缺陷 |
| `mechanism-search.md` + `scripts/domain_mms.py` | MMS 六方向（信息利用 / 先验适配 / 表示 / 优化动力学 / 测量-先验耦合 / 目标结构恢复）+ 十问方法候选契约 `MM1`–`MM8`；经既有 I2M 进入 R8 |
| `evaluation-policy.md` | 测量域目标 ≠ 整图重建 ≠ 局部结构；主/辅/结构指标与最小有意义改进阈值必须事前冻结 |
| `variants/cross-domain-generative-prior.md` | CT→MRI 生成先验适配任务配置（冻结主干 + FBS + 小容量 adapter；不因困难而默认解冻） |
| `variants/wave-3d-structure.md` | 3D Wave-TOF 任务配置（20-coil、z slab、Θ/Λ/Ω_val 分工、全局 NMSE ≠ 微血管恢复；Oracle 功效结论限定研究空间） |

## 4. Fixed in this release

- 运行时根解析此前分散在 `legacy_handoff` / `operational_reconcile` / `render_status`，
  现统一经 `rlp_paths.py`；歧义布局一律显式报错。
- 新项目 smoke 路径（release_check / research_replay）写 `.research-lifecycle-protocol/`，
  旧项目读取路径保持 `.research-idea-pipeline/`。

## 6. Compatibility

- canonical Research State 八类对象、R0–R14、CIE、四入口、16 Preset、Scheduler 八级
  优先级、PEIG/AALG、Evidence Qualification、预注册**均未改变**。
- 旧项目不重新 Bootstrap、不重置 state、不丢 evidence/failure/assurance/repair、
  不重置 AALG/PEIG 预算、不改原始产物。
- 历史 tag（`research-idea-pipeline/v*`）与 release notes 原样保留。
- 其他两个 skill（`academic-figure-draft-architect`、`scientific-manuscript-reviser`）无改动。

## 7. Known limitations

- 自动迁移不存在，也不在本版本提供；迁移只能是人工决定并按
  identity-and-compatibility.md §5 的步骤执行。
- TAG 的机制指纹比对是结构化的（mechanism / assumptions / scope / predictions / refs），
  不做语义等价证明；无法机械证明的等价关系会生成待审查判断，而不是自动阻断。
- 真实 CT-FM / Wave-TOF 项目回放需要项目私有数据，本版本只提供契约与合成 fixture。
