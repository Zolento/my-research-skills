# Research Lifecycle Protocol v2.0.1 — Domain Evidence Qualification & Execution-Path Integrity

**Release date:** 2026-11-10（本分支验收日期）· **Component:** `research-lifecycle-protocol/` · **Planned tag:** `research-lifecycle-protocol/v2.0.1`
**Status:** 在 `research-lifecycle-protocol/dev` 分支验收；tag 随合并进 `main` 时创建（annotated）。
**Base:** v2.0.0（`research-lifecycle-protocol/v2.0.0` @ merge commit `dacfcd6`）。

---

## 1. What this release is

v2.0.0 把 MRI Domain Profile 建成了"文档完善 + 独立检查器"的领域扩展；2.0.1 修复审查发现的
实现缺陷，让领域规则**真正参与科研决策**：TAG 的科学结论不再可被 Agent 自我认证，事件日志
满足并发完整性与幂等，DP12–DP14 进入真实 R9.O 裁决，MMS 接入 I2M 候选验证且无法绕过。

## 2. Defect-fix matrix（摘要）

| 缺陷 | 根因 | 修复 |
|---|---|---|
| 物理限制自我认证 | `classify()` 只看声明里的 `verified: true` | `limit_type` + `source_refs` 必须在 canonical state 中解析为当前可用证据；结论强度受 `limit_type` 约束（detection_power/empirical 为条件性结论；interpretation 不得自我升级） |
| 有效性缺陷自我认证 | 非空 `validity_findings` 直接判 `VALIDITY_BLOCKER` | 需要 `validity_evidence_refs` 解析为 failed 实验/已记录工程失败/已观测证据；纯文本声明 → `INSUFFICIENT_EVIDENCE` + `safety: hold_pending_verification`（有限安全审查，不登记为已验证故障） |
| 证据撤销/失效不追认 | 历史判定与当前 state 脱节 | 每次 `classify()` 对引用证据重做 validity + 一跳依赖检查；失效证据不支撑新结论 |
| 新证据 ID 逃逸 | 任何未见 ref 都算 novelty | 记录证据内容摘要；换 ID 内容等价 → 不构成增量；预测与历史相同 → 提示判别力不足 |
| 事件并发竞争 | 读链/算 seq 在锁外 | `append_event` 全程持有独立 lock file（读→验证→构造→追加→fsync 同一临界区） |
| 事件重复追加 | 无幂等标识 | `event_id`（route/state/action/fingerprint/verdict/kind 摘要）；重复提交返回已有事件 |
| Loop 拦截事件写回 | 无幂等且未区分事务 | 派遣事务与 TAG enforcement 事务分离；重复 apply 返回 DUPLICATE 不重复追加 |
| DP12–DP14 不可达 | 只被测试调用 | 接入 `evidence_outcome` 事务（`state_path` 线程化），领域违规阻止 SUPPORTED 确认但不删除实验记录 |
| 指标方向以正负推断 | 统一 `value < 0` | 冻结指标契约声明 `direction`；缺失方向 → 不足以支持结论而非猜测 |
| 冻结阈值可事后修改 | 只声明 `frozen_before_results` | 绑定预注册：`preregistration_ref` + `metric_contract_digest`，与实验冻结预注册内记录比对 |
| MMS 可绕过 | 独立 CLI 无人调用 | I2M 候选路径在 Profile 激活时强制调用 MMS 验证 |
| MMS 忽略损坏 TAG 日志 | `except Exception: records=[]` | 损坏链 → 显式错误（fail closed） |
| Profile 状态版本缺失 | `active_profile()` 不传 state | 统一传入当前 state，CLI/Loop/I2M/EO 同一判定 |

## 3. Verification（如实分级）

| 等级 | 状态 | 依据 |
|---|---|---|
| L1 实现有效性 | **已验证** | T01–T22 测试矩阵；domain selftests；负向测试先于修复在旧实现上复现失败 |
| L2 运行有效性 | **部分验证** | TAG 拦截/事件写回经 `preset_router` 真实 apply 入口；DP12–DP14 经 `evidence_outcome.apply`；多进程并发追加 |
| L3 科研有效性 | **NOT YET VALIDATED** | 未做真实 MRI A/B；合成回放只证明机制接线 |

## 4. Compatibility

- 协议命名空间、旧项目根、16 Preset、R0–R14、Scheduler 八级优先级、PEIG/AALG、
  Evidence Qualification 语义均不变；未声明领域 Profile 的项目行为与 2.0.0 逐字节一致。
- 历史研究与 tag（含 `research-idea-pipeline/v*`、`research-lifecycle-protocol/v2.0.0`）不改写。
- TAG 事件链向后兼容：新字段（`event_id`/`state_version`/`state_digest`/`evidence_digests`）
  为增量，旧链仍可通过校验。
