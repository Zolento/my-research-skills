# v2.3.1 — MRI coil combination and checkpoint selection

Date 2026-11-18. Tag `research-lifecycle-protocol/v2.3.1`.

- MRI evaluation combines complex coil images by summing their products with the conjugates of the stored CSMs. GT and reconstruction use the same image convention and GT RMS scale. NMSE uses complex images. PSNR and SSIM use magnitude images.
- Self-supervised training can use measurement splits and their losses to update weights. Select `best_val` by PSNR or NMSE on the full validation set against GT. Managed execution rejects declarations that use loss measurements for model selection.
