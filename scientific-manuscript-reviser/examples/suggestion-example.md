# Genuine editorial and scientific choices

## Scientific issue

A component removal changes model capacity and training compute. The manuscript
attributes the performance difference to a specific mechanism. Locate the actual
ablation protocol, observation and mechanism statement; do not fabricate section
or figure identifiers if they were not supplied.

Scientific logic verdict is UNDERDETERMINED. Missing identification does not prove
the proposed mechanism is false. This is Major, mechanistic reasoning with explicit
alternative explanations. Confidence depends on how clearly the protocol is reported.

- Repair A requires_text_change_only. After author resolution, calibrate the mechanism
  statement to an associative component comparison. This changes a protected claim
  and is high risk, so it cannot be auto-applied as stylistic naturalization.
- Repair B requires_reanalysis. Check whether existing measurements distinguish
  capacity/optimization explanations. New conclusions require actual analysis results.
- Repair C requires_new_experiment. Design a matched-capacity and matched-compute
  control that distinguishes the claimed mechanism. Describe it as proposed work.

Do not say a control was run or a mechanism was verified. The outline retains
SCIENTIFIC GAP TO RESOLVE where the mechanism would otherwise be asserted.

## Narrative issue

An already supported contribution becomes visible only late in the introduction.
Options are genuinely different operations

- A moves the actual problem constraint to the opening. It increases tension visibility
  while spending less space on broad background.
- B keeps paragraph order and states the target gap before the method. It preserves
  progression with a smaller edit.
- C retains the paragraph order and sharpens the opening's last sentence as tension.
  It preserves most author wording but delays the full contribution statement.

Every option preserves the same supported claim/evidence/scope. No “first”, broad
robustness or new causal interpretation is added to make a stronger contribution.

## Keep as is

“We measured error on Dataset A.” is concrete and natural. There is no reason to
replace measured with a more ornate synonym or force a mini conclusion after it.
