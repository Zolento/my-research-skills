# 4 Results: sensor drift detector

We evaluate the drift detector on the held-out split of three released sensor
logs. On that split the detector reaches precision 0.91 and recall 0.84. Every
run used the same hyperparameters, which makes the comparison across runs
meaningful.

We further report that a prior study observed comparable precision on a related
task. We have not reproduced that result here.

Scope: only the three sensor families present in the log set were measured, so
the result is bounded to those families and the held-out split.
