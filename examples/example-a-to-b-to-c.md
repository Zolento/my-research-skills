# 示例：串联调用 A → B → C

演示完整链路：从领域关键词出发，到 idea 清单，再到提案，最后到七子代理审查。

---

## 1. 调用 Mode A

```
调用 research-idea-pipeline，mode=A
输入：领域关键词="扩散模型 + 组合优化"，参考文献=[...]
```

**执行要点：**

1. 内联执行 Mode D：先查 `./local_literature/`，未命中再走 arxiv（含 429 退避），
   产出技术路线归纳表与创新性边界。
2. A2 逐路线做深度局限性分析 —— 每条"没做到"必须指向**具体未建立的结构性质**。
3. A3 **同一轮并发**派遣 6 个子代理（R-CVPR / R-ICML / R-NeurIPS / A-Author /
   A-Experimenter / S-Devil），每人 ≥3 个 idea，汇总去重后 ≥10 个。
4. A4 标注每个 idea 的推导策略。
5. A5 输出 idea 候选清单 + 技术路线归纳表 + 创新性边界界定。

**产物片段：**

| 编号 | 推导策略 | 核心思路 | 与现有工作差异 | 贡献类型 | 来源子代理 |
|---|---|---|---|---|---|
| I3 | 假设挑战 | 用扩散过程的可逆性约束组合优化搜索空间 | 现有方法把扩散当作采样器，未利用其可逆性作为可行性约束 | Concept & Feasibility | R-ICML |

→ `next_mode_suggestion: "B"`

---

## 2. 调用 Mode B

```
调用 research-idea-pipeline，mode=B
输入：idea="I3: 用扩散模型的可逆性约束组合优化搜索空间"
```

**执行要点：**

1. B1 三审稿人视角独立评估创新性，并**引用具体标准条目**；S-Lit 核实最接近
   先前工作，给出重叠度判定。
2. B2 S-Feas 给可行性评分 + 瓶颈；S-Theory 检查理论基础与隐含假设。
3. B3 六节提案展开，其中 §4 动机必须回答"为什么之前没人这么做"。
4. B4 十三节实验流程，含贡献—实验映射表与证伪条件。

**产物：** 论文提案（1500—2000 字）+ 实验流程计划书 + 创新性判定 + 可行性评分
+ 风险清单。

→ `next_mode_suggestion: "C"`

---

## 3. 调用 Mode C（首次复核）

```
调用 research-idea-pipeline，mode=C
输入：proposal=上一步输出
```

**执行要点：**

1. C1 判定为**首次复核**（无上一次审阅内容）。
2. C2 派遣七子代理：每人 **1—5 分** + ≥200 字意见（S-Repro ≥150 字）。
3. C3 交叉质询：每人至少一条质疑；评分差 ≥2 分记录分歧；汇总取**中位数**。
4. C4 输出审查结论卡片（优先级 / 最适合会议 / 核心优势 / 致命风险 / 修改建议）。

**产物：** 七子代理评审意见 + 交叉质询记录 + 审查结论卡片 + 横向对比表。

→ 若仍有未解决项，`next_mode_suggestion: "C"`（进入接续复核）
