# 评分与聚合政策（两层：硬门禁 + 排序维度）

R12（叙事审核）与 R7 / R10 / R13（方案复核）都要**多子代理审查**，但本轮起**聚合机制分两套**。
本文件是这两套机制的**唯一权威定义**。各 R 阶段 只保留自己**特有的部分**：

| 层 | 机制 | 适用 | 性质 |
|---|---|---|---|
| **第一层** | **硬门禁 `G1—G5`**（§3） | **R12** | `pass` / `fail` 直接判定。**不打分、不聚合、不平均**。任一 `fail` ⇒ `not_submission_ready` |
| **第二层** | **排序维度六维**（§4） | **R12** | 逐维 `1—5` + 理由 + 证据。六维**全部同向（高 = 好）** |
| **并行保留** | **极性归一化**（§2）、**逐维中位数与一票否决**（§5） | **R7 / R10 / R13** | R7 / R10 / R13 的现行规则**完整有效**，本轮不降级 |

| Mode | 本文件之外，各自保留 |
|---|---|
| **R12** | 六槽位与 claim graph 的生成、攻击面审稿人的派遣与输出格式（见 [roles.md](roles.md) §1B、§6） |
| **R7 / R10 / R13** | **八子代理分工**与审查焦点（见 [phase-r7-r10-r13-assurance-repair-review.md](phase-r7-r10-r13-assurance-repair-review.md) §E2.1） |

> **冲突时以本文件为准。** 若某 Mode 的写法与本文件不一致，属于规则漂移，应改该 Mode。

**R12 的退役项**（不得再作为 D 的现行规则出现）：反向维度、极性归一化、逐维度向量聚合、
单一综合评分、venue 打分角色。R12 的六个排序维度**没有反向维度**，因此 §2 不适用于 D。

### 六个 reviewer 不是独立样本（硬约束）

R12 的六个攻击面审稿人与 R7 / R10 / R13 的八子代理，都是**同一个基础模型换不同 prompt**。
它们的判断**高度相关（`corr ≫ 0`）**，**不是独立样本**。因此：

- **不得**用「6 个都同意」声称 **reviewer consensus**。一致只说明同一模型的同一种读法
  重复出现，不提高结论的可靠性。
- 不得把"给了高分的子代理有几个"当作置信度、概率或显著性。
- 需要更可靠的结论时，只能补**外部证据**（实验 / 定理 / 负检索记录），不能靠加同源 reviewer。

## 1. 评分标尺与锚点（1—5）

**所有进入聚合的维度都使用同一把 1—5 的尺子：**

| 分 | 含义 |
|---|---|
| 5 | 无实质缺陷，可直接投稿 |
| 4 | 小修可解决 |
| 3 | 有明显缺陷，但可修复；需要大修 |
| 2 | 存在结构性缺陷，修复成本高 |
| 1 | 根本性错误 / 不可行 / 不成立 |

**要求：** 每个评分必须有理由，且**引用具体证据**（具体实验缺失、具体引用、具体
逻辑缺口）。使用 [roles.md](roles.md) §5 的统一输出骨架。

---

## 2. 极性归一化（仅适用于仍使用反向维度的 Mode；当前为 R7 / R10 / R13）

**适用范围（本轮限定）：** 本节**只对仍使用反向维度的 Mode 生效，当前为 R7 / R10 / R13**。
**R12 不执行本节任何归一化** —— 它的六个排序维度（§4）全部同向，**没有反向维度**。

R7 / R10 / R13 的规则（**保留，不变**）：**各子代理的打分方向并不一致。所有进入聚合的维度，
必须先统一为「分数越高越好」。**

| 维度 | 原始极性 | 归一化 |
|---|---|---|
| 绝大多数维度（会议审稿人的通用角度与会议特性维度、S-Feas 等） | 高 = 好 | **原值** |
| **S-Devil 的「新颖性反驳」** | **低 = 好**（`5 = 完全无新颖性`） | **新颖性稳健度 = 6 − 反驳分** |

⚠️ **不先归一化就直接聚合，会把最 novel 的方案否决、把「完全无新颖性」当成高分** ——
这是本流水线明令禁止的错误。

- **新增维度必须在维度矩阵里显式标注极性并给出归一化公式。**
- 归一化后的值才允许进入中位数。
- 汇总表里**同时给出原始分与归一化分，并标注方向**。

> **`6 − 反驳分` 没有概率解释。** 它只是把反向刻度翻成同向刻度的记账变换，不得据此
> 声称「新颖性稳健度 = 80%」这类置信度。**R12 不使用该公式**：novelty 由 `R-Novelty`
> （同向维度 `Originality`）与 `G2` 门禁承担（见 §3、§4 与 [roles.md](roles.md) §1B）。

## 3. 硬门禁 G1—G5（不打分、不聚合、不平均）

**第一层是门禁，不是评分。** 门禁只有两个判定值：`pass` / `fail`。
R12 的 D7 对**每一套候选叙事**逐项判定下列五项。

| Gate | Fail 条件 | 主责攻击面 | 判定依据来源 |
|---|---|---|---|
| `G1 Claim grounding` | central claim 找不到对应证据 | R-Generalization + 汇总者 | `S5 Evidence Contract` 的 `Ci ← Ej` 逐条核对；`[待补]` 项 |
| `G2 Prior-work distinction` | 与最近工作没有明确的 delta | R-Novelty | S-Lit 的最接近工作（≥5 篇）+ L3 负检索记录 |
| `G3 Identification` | 实验 / 证明不能识别所声称的机制 | R-Causal + R-Experimental | confounder / 替代解释清单 + S-Devil 的最简解释反例 |
| `G4 Factual integrity` | 定理 / 实验 / 结果被叙事夸大 | R-Theory（+ R-Experimental） | 定理与实验的原始范围 vs 叙事句；[evidence-policy.md](evidence-policy.md) §1、§3 |
| `G5 Venue scope` | 贡献对象与 venue 明显不匹配 | R-Utility + D6 venue calibration | [venue-standards.md](venue-standards.md) 的贡献对象 ↔ venue 校准 |

**判定规则（强制）：**

1. **任一 `fail` ⇒ `not_submission_ready`**，不得推荐为最佳叙事。
2. **不得把门禁折算成 1—5 分**，不得求平均、加权或多票裁决。五个门禁之间**不可交易**：
   一个 `pass` 不能抵消另一个 `fail`。
3. **门禁失败的候选不参与 §4 的六维排序**（见 D8）。六维高分也救不回 `fail`。
4. 每个门禁判定必须写出**依据位置**（具体 `Ci ← Ej`、具体槽位、具体定理或实验编号）。
   写不出依据的，不得判 `pass`。
5. 判定依据是**证据**，不是**票数**。六个 reviewer **不是独立样本**（同一基础模型换
   prompt，`corr ≫ 0`），因此**不得以「6 个都同意」声称 reviewer consensus**，也不得用
   「多数认为 `pass`」代替证据。
6. R12 **不再使用** §5 的类别门禁。S-Devil 的致命弱点清单与最简解释反例**喂 `G3` / `G4`**，
   由本节规则直接裁决。
7. 门禁枚举**冻结**：不得增删、改名或意译 `G1—G5` 及其英文名。

## 4. 排序维度六维（1—5，逐维必须给理由与证据）

**门禁通过之后才排序。** 排序只用下面六个维度，枚举逐字如下（不得改名、不得意译）：

| 维度（逐字） | 问什么 | 主责攻击面审稿人 | 喂哪个门禁 |
|---|---|---|---|
| `Significance` | 即使正确，谁会在意？改变了什么？ | R-Utility | `G5` |
| `Originality` | 最近工作是否已做过？delta 是否非平凡？ | R-Novelty | `G2` |
| `Soundness margin` | 结论离证据边界还有多远？（baseline / 公平性 / confounder / 统计功效；assumptions / proof / tightness / definition） | R-Experimental（实验侧读数）+ R-Theory（理论侧读数） | `G3`、`G4` |
| `Explanatory depth` | 所谓机制是否只是相关性 / 事后解释？ | R-Causal | `G3` |
| `Generality` | claim scope 是否超出证据？ | R-Generalization | `G1`、`G5` |
| `Narrative compression` | 要让审稿人**正确理解**该 claim，最少还需要补多少说明？ | 汇总者（依六槽位 `S1—S6` 与六份攻击报告） | — |

**规则（强制）：**

1. **六维全部同向（高 = 好）**，没有反向维度，因此**不做极性归一化**（§2 不适用于 D）。
2. 使用 §1 的 `1—5` 标尺。**每个分数必须给理由，并引用具体证据**（具体实验缺失、具体
   引用、具体逻辑缺口、具体槽位）。写不出证据指向的分数无效。
3. **不做跨审稿人的逐维中位数，也不把六维折算成一个「综合评分」来选最佳。** 六个 reviewer
   **不是独立样本**（同一基础模型换 prompt，`corr ≫ 0`），中位数是**伪精确**。
   `Soundness margin` 允许**两个读数**（实验侧 / 理论侧）并存，**不得平均成一个数**。
   同一维出现不同读数时，全部列出并标注分歧。
4. **排序（D8）= 逐维比较**：必须显式写出**决定胜负的维度**与**付出的代价维度**。
   若流程确实需要单一排序键，**必须显式写出权重与理由**，不得隐式偏重 `Originality`。
5. 六维读数允许**一个例外用途：状态标记**。当其它文件（例如 INDEX 的 Warnings 阈值）
   明确要求一个粗粒度水平时，允许取「六维读数的中位数 `< 3`」作标记。
   这类标记**不是聚合、不是综合评分**，**不得**进入排序、**不得**用于最佳叙事推荐、
   **不得**把门禁 `fail` 的候选救回来。
6. 排序只在**通过 `G1—G5`** 的候选之间进行。不得反过来用六维高分掩盖门禁 `fail`（§3）。

## 5. 逐维中位数与一票否决（**R7 / R10 / R13 仍适用**；R12 已改用 §3 门禁 + §4 六维）

> **适用范围：R7 / R10 / R13。** R7 / R10 / R13 的现行聚合规则在本轮**完全不变**。
> **R12 不使用本节任何一条**：不做归一化后的中位数、不做一票否决、不走「带条件的
> 推荐」出口。D 的对应机制是 §3 的门禁与 §4 的六维排序。
>
> 本轮登记为 P1 待办：R7 / R10 / R13 迁移到 `G1—G5` 门禁 + 六维排序 + 攻击面审稿人后，§2 与本节
> 可整体退役。

**R7 / R10 / R13 的类别门禁（保留，先于中位数，直接否决）：** 由 S-Lit / S-Devil 的**类别结论**触发：

1. **S-Lit 判定「已被覆盖」** → 否决；
2. **S-Devil 指出的致命弱点含「不可缓解的根本缺陷」** → 否决；
3. **任一门禁项标注「存在评审分歧」且未收敛** → 不得推荐为最佳。

**逐维度中位数（不用平均值）：**

1. 把每个子代理的每个**归一化维度**汇成**维度矩阵**；
2. 每个维度取**中位数** → **维度中位数向量**；
3. **综合评分** = 各归一化维度中位数的**等权中位数**；若采用加权，**必须显式写出
   权重与理由**，不得隐式偏重创新性；
4. **分歧单列**：评分差异 ≥ 2 分的维度必须记录分歧点并尝试协商；无法收敛的明确标注
   **「存在评审分歧」**。分歧与中位数**并存**，不得被中位数掩盖。

**为什么用中位数（R7 / R10 / R13）：** 避免被极端值拉偏 —— 尤其 S-Devil 的**敌对打分**。
⚠️ **方向提醒：** 归一化后**稳健度越高越好**，因此会污染结果的是 S-Devil 的
**原始高分**（`反驳分 5` → 稳健度 1），**不是**它的"极端低分"——那反而是好的一端。

**一票否决（只针对归一化后的 1—5 维度）：**

**任一归一化维度中位数 ≤ 2** → 该方案**不得被推荐为最佳** /
**不得判为「推荐优先级 = 高」**。典型情形：

- 创新性 5 但**可验证性 1**（无法验证）→ 不可推荐；
- 创新性 5 但**理论严谨性 1**（迁移证明不成立）→ 不可推荐；
- **理论角度 ≤ 2** 或 **应用角度 ≤ 2** → 不可推荐；
- **S-Devil 归一化后的稳健度 ≤ 2**（即反驳分 ≥ 4，几乎没有新颖性）→ 不可推荐。

> ⚠️ 注意最后一行方向：**是「反驳分高」被否决，不是「反驳分低」被否决。**

### 5.1 「带条件的推荐」出口（不得静默忽略）

某归一化维度中位数 ≤ 2 时，**默认不可推荐**；**但允许「带条件的推荐」**：

- 必须写明**该维度为何可接受**（不是"以后再说"，而是给出该低分不构成致命问题的具体理由）；
- 必须写明**缓解路径与验证点**（谁、在什么阶段、用什么实验/检索来验证缓解成立）；
- **不得静默忽略**：要么否决，要么带条件推荐并留下上述说明，二者必居其一。

> 本出口**不适用于门禁**：R7 / R10 / R13 的类别门禁仍是直接否决，R12 的 `G1—G5`（§3）同样是
> 直接判定，都不能靠"带条件推荐"绕过。

## 6. 计数与类别维度不进向量

以下维度**不参与任何聚合读数**，只作**上下文记录**或**门禁依据**：

| 维度 | 性质 | R12 处理 | R7 / R10 / R13 处理 |
|---|---|---|---|
| S-Devil 的「致命弱点条数」 | 计数，越少越好 | 不进六维；只作上下文记录 | 不进中位数向量 |
| S-Lit 的「新颖性核实结论」（确认新颖 / 部分重叠 / 已被覆盖） | 类别值 | 喂 `G2`（§3） | 喂 §5 的类别门禁 |
| 攻击面审稿人的定性结论（证伪 / 严重 / 可修 / 未发现） | 类别值 | 写进 §4 的**理由与证据**，不折算成分数 | — |
| 贡献类型判定等其它类别值 | 类别值 | 只作上下文记录 | 只作上下文记录 |

> R12 **没有聚合向量**，"不进向量"在 R12 指**不进 §4 的六维排序读数**。
>
> 若某个计数或类别维度确实需要参与量化比较，**必须先把它显式转成一个同向的 `1—5` 读数
> 并说明极性**（R12 只能落在 §4 的六维之内），否则不得进向量。
